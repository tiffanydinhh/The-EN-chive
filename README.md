## The EN-chive
**THE EN-CHIVE** is a multi-page front-end website that showcases the discography of the K-Pop group ENHYPEN. Through exploring the various webpages, users can learn more about the group and their music.

## Purpose
This project was developed to strengthen my front-end development skills, as it allowed me to:
* Design a functional website from scratch
* Create UI designs and wireframes, then translate them into functional elements
* Implement reusable React.js components

## Features
* Home Page: Interactive content blocks with hover animations customized to each ENHYPEN album concept.
* Album Pages: Organized information about the album, clickable tracklist, and concept images.
* Title Track Pages: Organized information about the title track, lyrics, and member line distributions
* Contact Page: Interactive contact-styled form
* About Page: Simple about information highlighting the website's purpose and acknowledgements.
* Animations: Hover animations using CSS transitions
